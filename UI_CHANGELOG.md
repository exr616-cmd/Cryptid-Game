# V147 — Contextual UI

The gameplay screen now follows the requested rule:

- Only actions relevant to the current situation are shown.
- Stealth, tactical combat, and investigation appear contextually based on the current scene.
- Codex, Inventory, and Journal are always accessible.
- Save/Load remain available.
- The persistent right-side area no longer lists generic actions that may not apply.
- Codex contains the major and lesser cryptid roster plus the current threat.
- Inventory shows current equipment.
- Journal shows the investigation log.
