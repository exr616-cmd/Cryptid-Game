# Nocturne County V146 — Fixed Playable Build

The previous V145 integration started with chapter 1 but chapter 1 was not actually defined in the build, so the renderer fell back to a static CASE FILE screen with no controls. V146 fixes that by supplying chapters 1–12 and a real starting scene, while retaining chapters 13–15.

The game now starts immediately in Chapter 1 and exposes Stealth, Tactical Combat, Investigate, choices, Save, New Game, evidence, status, relationships, weather/time, and chapter progression.
